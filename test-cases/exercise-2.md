**Exercício: Criação de Casos de Teste para a Feature "Enviar Dinheiro"**

Imagine que a feature "Enviar Dinheiro" é uma funcionalidade crítica no aplicativo Real World App. Seu objetivo é criar casos de teste para garantir que essa funcionalidade funcione corretamente. Considere os seguintes cenários como exemplo:

**1. Caso de Teste: Enviar dinheiro com saldo suficiente.**

- Descrição: Verifique se é possível enviar dinheiro para um amigo quando o saldo da conta é suficiente.

**2. Caso de Teste: Enviar dinheiro com saldo insuficiente.**

- Descrição: Garanta que o sistema exiba uma mensagem de erro ao tentar enviar dinheiro sem saldo suficiente.

<br>

# Casos de Teste

| CT-06                    | Enviar dinheiro com saldo suficiente                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Pré-condições**        | 1. O usuário está autenticado no sistema.<br>2. O usuário possui saldo igual ou superior a `$ 1.00`.                                                                                                                                                                                                                                                                                                 |
| **Passo a passo**        | 1. Verificar se o botão `New` está sendo exibido na barra superior da tela. <br> 2. Clicar no botão `New`.<br> 3. Buscar o contato digitando o nome no campo de busca e clicar no contato encontrado, ou selecionar um contato recente exibido na tela. <br> 4. Preencher o campo `Amount` com o valor `1`.<br> 5. Preencher o campo `Add a note` com o texto `Teste`.<br> 6. Clicar no botão `Pay`. |
| **Resultado esperado**   | 1. Um toast verde de sucesso é exibido no canto inferior esquerdo com a mensagem `Transaction submitted!`.<br> 2. O nome e o avatar do contato são exibidos centralizados na tela.<br> 3. A mensagem `Paid $1.00 for Teste` é exibida, centralizada, abaixo do nome do contato.<br> 4. Os botões `Return To Transactions` e `Create Another Transaction` são exibidos abaixo da mensagem.            |
| **Resultado encontrado** | Conforme o esperado.                                                                                                                                                                                                                                                                                                                                                                                 |
| **Status**               | ✅ Passou                                                                                                                                                                                                                                                                                                                                                                                            |
| **Suíte de teste**       | Tela de transações                                                                                                                                                                                                                                                                                                                                                                                   |
| **Ambiente de teste**    | Web - Google Chrome 156.0.8078.80 (64 bits) - Windows 11                                                                                                                                                                                                                                                                                                                                             |     |

<br>
